How it works

Your server stays light

Heavy work and all saved data live on the central server, not on your Minecraft server.

Plugins

Run on your Minecraft server, one feature each. They never connect to a database.

Core

The only plugin that talks to the central server. Every other plugin sends its requests through Core.

Central server

A separate service that does the heavy processing and stores every plugin's data.

  1. PluginOn your server
  2. CoreOn your server
  3. Central serverSeparate service
  4. DatabaseBehind the central server

The answer travels back the same way, so your Minecraft server keeps one connection instead of one per plugin.

Plugin layers

How plugins depend on each other

Plugins are grouped into layers so they never tangle into each other.

  • Same layer, no linksPlugins in the same layer never depend on or talk to each other.
  • Lower layers may use higher onesA plugin can use plugins from a higher layer, but only as an optional extra it can run without.
  • Core is open to everyoneAny plugin, in any layer, can use Core to reach the central server.

Events

Plugins can react to each other

Every plugin announces its main actions as server events. Other plugins can listen to them and, where it makes sense, cancel the action. That lets plugins change each other's behaviour without being tied together. Each plugin page lists its events.
