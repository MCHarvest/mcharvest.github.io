Layer 1 plugin

MCHarvest Core

The gateway between your Minecraft server and the MCHarvest central server. Install it whenever you use any other MCHarvest plugin.

SpigotMC PaperMC FoliaMC

What it does

  • One connectionOpens the single connection from your Minecraft server to the central server.
  • A gateway for every pluginEvery other MCHarvest plugin sends its requests through Core, whatever layer it is in.
  • Token stays with your serverSigns each request with your central server token and never follows redirects, so the token only goes to the address you configured.
  • No freezesSends requests in the background, so a slow central server never pauses your game.

Supported servers

One jar runs on all three. Core detects the server when it starts and picks the matching task scheduler.

SpigotMC
Uses the standard Bukkit scheduler.
PaperMC
Uses the standard Bukkit scheduler.
FoliaMC
Uses FoliaMC's region-aware scheduler, so work runs on the thread that owns each part of the world.

Installation

  1. Get the MCHarvestCoreEngine jar.
  2. Put it in your server's plugins folder and start the server once. Core writes its settings file to plugins/MCHarvestCore/config.yml.
  3. Set the central server address and token in that file, then restart the server.
Core turns itself off when settings are wrong

If the address is empty or the timeout is not a positive number, Core logs the problem and disables itself. Fix the setting and restart.

For plugin developers

Build against the Core API, published as io.github.mcharvest:core-api, and list Core as a dependency in your plugin description. The API hands you the central server gateway; Core looks after the connection.

Questions

What happens when the central server is unreachable?

Core tells the plugin that sent the request that it failed. Core does not retry on its own; each plugin decides what to do next.

Does Core store any data?

No. Core only carries requests. All data is stored by the central server.

Can other MCHarvest plugins run without Core?

They need Core to reach the central server, so install Core alongside them.
