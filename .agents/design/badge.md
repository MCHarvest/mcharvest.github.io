# Badge and chip

Styles in `css/shared/components.css`.

| Class | Use |
|---|---|
| `.badge` | Small pill label, neutral silver. |
| `.badge--accent` | Accent label (e.g. a plugin's layer). |
| `.badge--ok` | Positive status (e.g. "Yes" in a cancellable column). |
| `.badge--warn` | Caution status. |
| `.chip-row` > `.chip` | Row of outlined pills for tags, e.g. supported servers. |
