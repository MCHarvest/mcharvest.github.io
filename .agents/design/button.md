# Button

Styles in `css/shared/components.css`.

| Class | Use |
|---|---|
| `.btn` | Pill button, `--glass-strong`, hairline border, lifts 1px on hover. |
| `.btn--primary` | Accent gradient (`--accent` to `--accent-strong`), white text. |
| `.btn--sponsor` | Sponsor gradient, white text. |
| `.btn-row` | Wrapping row of buttons, 12px gap. |

Use `<a class="btn">` for navigation and `<button class="btn">` for actions.
