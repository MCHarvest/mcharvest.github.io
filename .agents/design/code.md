# Code

Styles in `css/shared/components.css`.

* `pre`: dark block (`#1c2431`, text `#e6ebf2`), `--mono`, `.88rem`,
  `overflow-x: auto`.
* Inline `code`: `--accent-soft` background, `--accent-strong` text, may break
  anywhere outside tables.
* `.code-label`: small caption above a `pre`.

MCHarvest site rule: the documentation pages contain no code snippets. Inline
`code` is used only for file names, folder names and setting names.
